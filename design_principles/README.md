# Design Principles & Aesthetic Systems

This directory houses curated, multimodal-ready design system packages for AI coding agents. While top-level language directories (`css/`, `javascript/`, `wizz/`) define platform-native technical mechanics, `design_principles/` defines cohesive **visual languages, optical physics, color palettes, component geometry, and accessibility rules**.
